
# Słownik odpowiedników usług chmurowych

Zestawienie pięciu rodzajów usług chmurowych oferowanych przez trzech głównych dostawców: Amazon Web Services (AWS), Microsoft Azure oraz Google Cloud Platform (GCP).

| Rodzaj usługi | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Maszyny wirtualne | EC2 | Virtual Machines | Compute Engine |
| Pamięć obiektowa | S3 | Blob Storage | Cloud Storage |
| Dyski blokowe | EBS | Managed Disks | Persistent Disk |
| Sieć wirtualna | VPC | Virtual Network | VPC |
| Relacyjna baza danych | RDS | Azure SQL Database | Cloud SQL |
